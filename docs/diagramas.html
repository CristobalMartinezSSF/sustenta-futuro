2. Flujo principal: de visitante a proyecto entregado

flowchart TD
    A[Visitante en landing] --> B[POST /leads]
    B --> C[(leads status=new)]
    C --> D[Enrichment IA]
    D --> E[Panel admin - Leads]
    E --> F{Revision}
    F -->|descartar| G[(status=lost)]
    F -->|avanzar| H[Ficha de evaluacion]
    H --> I[(lead_evaluations)]
    I --> J{Veredicto}
    J -->|no viable| G
    J -->|viable| K[Generar propuesta]
    K --> L[Numero COT-NNN-AAAA]
    L --> M[Render PDF HTML a Chromium]
    M --> N[(lead_proposals versionada)]
    N --> P[Enviar al cliente - Resend]
    P --> Q{Acepta?}
    Q -->|no| G
    Q -->|si| R[Convertir en proyecto]
    R --> S[(projects)]
    S --> T[Fases + Tareas Kanban]
    T --> V[(status=won entregado)]
